# 📱 移动端适配计划

## 现状

- 页面数：~27 个主要页面（员工 11 + 销售 7 + 经理 8 + 管理 1）
- 框架：React + Tailwind CSS v4 + Vite
- viewport meta 已设置 ✅
- **当前问题**：
  - 侧边栏固定宽度 `w-64`，手机屏被挤占
  - 大量 `p-6` / `flex justify-between` 在小屏溢出
  - 表格在手机上无法阅读
  - 弹窗 `max-w-2xl` 超出屏幕
  - 没有底部导航，依赖侧边栏

---

## 阶段一：布局框架（先做）

### 1. 底部 Tab 导航替代侧边栏
- `EmployeeSidebar` / `ManagerSidebar` / `AdminSidebar`
- md 以下隐藏侧边栏，显示底部固定 Tab 栏
- 底部 Tab：首页、学习中心、复盘、我的（按角色调整）

### 2. Navbar 移动端优化
- 缩小 logo 文字
- 用户菜单从"下拉列表"改为"头像点击展开"
- md 以下简化显示

### 3. 全局 Padding 收缩
- `p-6` → `p-4 md:p-6`
- `px-6` → `px-4 md:px-6`
- `max-w-5xl mx-auto` 保持，但增加侧边 `px-4`

---

## 阶段二：各角色首页

### 4. 员工首页 (`EmployeeHomePage`)
- 两列快速操作 → 单列堆叠
- `lg:grid-cols-5` 最近复盘+优秀录音 → 手机单列
- 复盘记录列表：横向标签不换行，按钮缩小
- 优秀录音：改为横向滚动卡片

### 5. 经理/主管首页
- 统计卡片：`grid-cols-4` → `grid-cols-2 md:grid-cols-4`
- 待办列表：全宽卡片

### 6. Admin Dashboard
- 统计行：单列堆叠
- 用户表格 → 卡片列表（或横向滚动表格）

---

## 阶段三：核心功能页

### 7. 复盘相关
- **新建复盘** (`DebriefNewPage`)：表单单列，步骤条缩小
- **报告页** (`DebriefReportPage`)：
  - 得分卡片从横向改为纵向堆叠
  - 雷达图缩小或改为横向滚动
  -  transcript 区域全宽
- **列表页** (`DebriefListPage`)：表格 → 卡片列表

### 8. 学习中心
- **产品列表**：`grid-cols-1 sm:grid-cols-2 lg:grid-cols-3`
- **详情页**：侧边栏资料改为上方折叠面板或底部 Tab

### 9. 对话训练
- **对话页**：消息气泡全宽，底部输入框固定
- **训练结果**：能力分析纵向堆叠

### 10. 产品测验
- 选项按钮：`grid-cols-1` 全宽堆叠
- 题目导航：横向滚动

### 11. 个人中心 (`ProfilePage`)
- 信息卡片：单列堆叠（头像+姓名在上，字段在下）
- 复盘记录表格 → 卡片列表

---

## 阶段四：交互优化

### 12. 触摸优化
- 按钮最小 44px 点击区域
- 底部 Tab 固定，`pb-safe` 适配 iOS 刘海

### 13. 弹窗/图片
- 弹窗 `max-w-md mx-4`，手机上贴边
- 图片预览支持手势缩放（如有需要）

### 14. 音频播放
- 播放条简化，显示在底部固定栏

---

## 实施建议

按以下顺序逐个改，每个改完就能测：

1. **底部 Tab 导航**（影响所有页面，先做）
2. **员工首页**（用户打开最多的页面）
3. **复盘报告页**（核心功能，内容多）
4. **学习中心/测验**（高频使用）
5. **个人中心/列表页**（表格改卡片）
6. **经理/Admin 页面**

每个阶段可以单独提需求，也可以一次做完。你看怎么搞？
