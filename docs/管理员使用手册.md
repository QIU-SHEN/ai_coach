# AI 销售陪练系统 — 管理员使用手册

> 适用角色：系统管理员

---

## 一、管理员权限说明

作为系统管理员，你拥有最高权限，可以：
- 👤 用户管理：创建、编辑、重置密码、分配主管
- 📚 知识库管理：培训资料、话术脚本
- 🏷️ 产品素材管理：产品线、图片、文档
- ⚙️ 系统配置：AI 模型、ASR 引擎、SMTP 等

---

## 二、用户权限管理

### 2.1 查看用户列表
进入「用户权限管理」页面：
- 所有主管自动展开，显示其下属员工
- 未分配主管的员工单独显示
- 可按姓名/工号搜索，按角色筛选

### 2.2 新增用户
点击「新增用户」按钮：
- 填写：用户名、密码、姓名、角色
- 员工可填写工号，主管/管理员可不填
- 创建后该用户即可登录

### 2.3 重置密码
点击用户旁的「重置密码」：
- 输入新密码（至少 6 位）
- 确认后立即生效

### 2.4 批量分配主管
1. 点击员工左侧的复选框（可多选）
2. 底部出现批量操作栏
3. 点击「批量分配主管」
4. 选择目标主管，或清空（取消分配）
5. 确认后生效

### 2.5 主管结构
- 一个员工只能归属于一位主管
- 主管也可以有上级主管（递归结构）
- 管理员不受主管权限限制，可查看所有数据

## 三、团队数据

进入「团队数据」查看全局统计：
- 主管数、员工数、复盘总数
- 各主管团队的复盘分布
- 平均分趋势

---

## 四、知识库管理

### 4.1 培训资料
上传/管理销售培训文档：
- 支持 PDF 格式
- 可关联到特定产品线
- 可为资料配置测验题

### 4.2 话术脚本
管理常用销售话术：
- 按场景分类（开场、异议处理、成交等）
- 员工在练习和复盘中会参考这些话术

---

## 五、产品素材管理

### 5.1 产品线
- 创建产品线（如"净水器 X6"）
- 编辑名称、描述
- 删除（仅清空该产品线下的所有素材）

### 5.2 图片与文档
与主管权限相同，可管理所有产品线的：
- 图片上传/删除
- PDF 文档上传/删除
- AI 生成产品介绍

### 5.3 AI 功能
管理员可使用全部 AI 功能：
- **AI 摘要**：提取产品核心卖点
- **AI 分类**：自动归类素材
- **AI 标签**：自动打标签
- **AI 提取文字**：OCR 识别图片/PDF 文字
- **AI 生成产品介绍**：基于选中图片自动生成文案

## 六、系统配置

进入「系统配置」页面，管理以下设置：

### 6.1 AI 模型配置
- **OpenAI API Key**：用于对话训练、报告生成
- **模型选择**：如 gpt-4、gpt-3.5-turbo
- **Base URL**：如果使用第三方代理（如 yunwu.ai）

### 6.2 ASR 配置
- **引擎选择**：阿里云 NLS / 本地 Whisper
- **阿里云配置**：AppKey、AccessKey ID/Secret、区域
- **本地 Whisper**：URL 地址

### 6.3 SMTP 配置
- 用于发送密码重置邮件
- 支持 QQ 邮箱、企业邮箱等
- 配置项：Host、Port、账号、授权码

### 6.4 前端地址
- 密码重置邮件中的链接域名
- 如：`https://qiushen.top`

## 七、运维注意事项

### 7.1 数据库备份
建议定期备份数据库：
```bash
mysqldump -u aicoach -p ai_sales_coach > backup.sql
```

### 7.2 文件存储
- 录音文件保存在 `backend/uploads/`
- 产品图片保存在 `backend/uploads/materials/`
- 定期清理不需要的文件以释放空间

### 7.3 服务重启
修改后端代码后需重新编译并重启：
```bash
cd /www/wwwroot/ai-sales-coach/backend
npm run build
pm2 restart ai-sales-coach-api
```

### 7.4 前端更新
修改前端代码后需重新构建：
```bash
cd /www/wwwroot/ai-sales-coach/frontend
npm run build
```

nginx 已配置 `index.html` 不缓存，刷新页面即可生效。

## 八、常见问题

**Q：用户忘记密码且未绑定邮箱？**
A：管理员可在「用户权限管理」中直接重置该用户密码。

**Q：录音分析失败？**
A：检查 ASR 配置是否正确，或查看后端日志 `/root/.pm2/logs/`。

**Q：邮件发送失败？**
A：检查 SMTP 配置，特别是 QQ 邮箱需使用「授权码」而非登录密码。

**Q：AI 响应慢或报错？**
A：检查 OpenAI API Key 是否有效，余额是否充足，Base URL 是否正确。

**Q：如何添加更多管理员？**
A：创建用户时选择角色为「系统管理员」即可。
